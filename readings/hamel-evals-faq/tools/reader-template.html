01 / PDF

Áp highlight lên PDF gốc

Giữ nguyên 61 trang, chữ, hình, mục lục và liên kết. Highlight là lớp chú thích PDF; có thể chọn, sửa hoặc xóa trong ứng dụng hỗ trợ.

  1. Mở PDF chính thức của tác giả rồi lưu về máy.
  2. Chọn file vừa tải ở bên dưới.
  3. Bấm tạo bản highlight và mở file kết quả.
Mở PDF chính thức ↗
Xử lý file ngay trên máy. Không tải file của bạn lên máy chủ.
Khi PDF đã thay đổi phiên bản

Công cụ kiểm tra SHA-256 trước khi áp tọa độ. Nếu tác giả đã cập nhật PDF, công cụ dừng để tránh tô sai chỗ. Dùng cách HTML bên cạnh hoặc cập nhật bộ tọa độ.

02 / HTML

Highlight trên giao diện web

Giữ nguyên cấu trúc bài, hình và liên kết. Mỗi mục có nhãn ưu tiên; dùng thanh công cụ trong bản xem trước để ẩn màu, lưu HTML hoặc in thành PDF.

  1. Mở trang gốc và lưu dạng HTML, hoặc dùng lệnh bên dưới.
  2. Chọn file HTML đã lưu.
  3. Đọc bản xem trước; bấm Lưu HTML hoặc In / lưu PDF.
Mở bài gốc ↗
CSS và hình gốc có thể cần mạng khi mở file HTML.
Lấy HTML bằng một lệnh
curl -L "https://hamel.dev/blog/posts/evals-faq/" -o evals-faq.html

Trên Windows cmd có thể dùng curl.exe. Lệnh lấy HTML trực tiếp, thuận tiện hơn bản lưu có tên thư mục tài nguyên khác.

Đây là công cụ áp highlight, không chứa toàn văn bài. Bộ dữ liệu chỉ có vị trí đánh dấu, mức ưu tiên và dấu kiểm tra phiên bản. File gốc do bạn lấy trực tiếp từ tác giả. Chế độ PDF hoạt động ngoại tuyến sau khi có file; chế độ HTML cần truy cập tài nguyên của trang cho đến khi gom đủ CSS, font và hình.
